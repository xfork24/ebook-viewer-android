# M1 行走骨架 — 设备端验证清单

**代码侧已验证**（无需设备）：
- book-parser 140 项单测全绿（含 golden 对拍：manifest 深比较 + 每文件 JSON 逐字节相等，覆盖 SVG/RTL/中文/多 body fixture）
- app 37 项单测全绿（桥接协议 / URL 服务 / host 层集成：qt-ready→create_view→start_book_load 时序、桥未挂载时的延迟加载、指纹稳定暂存、位置恢复回灌）
- `:app:assembleDebug` 构建成功

**设备端步骤**（需真机或模拟器；重点：掌阅 iReader，其次普通 LCD 手机/平板）：

## 0. 安装

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 1. 首次启动（桌面/主页）

- [ ] 冷启动 ≤ 3s 出现 viewer.js 主页（书图标 + 最近打开空列表）
- [ ] 无 ANR / 闪退；`adb logcat -s ViewerJS ViewerServer MainActivity` 无错误刷屏
- [ ] 断网/飞行模式下行为完全一致（全部请求被拦截，零网络 I/O）

## 2. 打开一本书（SAF）

- [ ] 主页点"选择书籍"→ 系统文件选择器 → 选 EPUB → 出现"正在准备书籍…" → 正文渲染
- [ ] 文件管理器直接打开 EPUB（ACTION_VIEW intent）同样可读
- [ ] 翻页流畅：点按左右翻页区、滑动
- [ ] 音量键上/下 = 上/下翻页，且系统音量不变化
- [ ] 物理翻页键（掌阅侧键，若机型支持第三方按键翻页）
- [ ] 页码进度、跳转（goto 面板）、TOC 面板、书签面板可用

## 3. 位置恢复（进程被杀）

- [ ] 读到任意位置 → `adb shell am kill dev.calibre.viewer`（或开发者选项"不保留活动"后划掉）
- [ ] 重新打开同一本书 → 回到上次位置（≤ 2s 防抖窗口内的位置）

## 4. 偏好持久化

- [ ] 调整字号/阅读模式（分页/滚动）→ 杀进程 → 重开 → 偏好保留

## 5. 渲染进程崩溃恢复（可选，需触发）

- [ ] 大书渲染中在开发者选项限制后台内存/手动 `adb shell am crash dev.calibre.viewer`（杀渲染进程不易精确触发，可跳过）
- [ ] 预期：页面自动重建（黑屏一闪）→ 重新 create_view → 回到最后保存的阅读位置，而非冻结或回主页

## 6. 控制台干净（chrome://inspect）

- [ ] Chrome 打开 `chrome://inspect` → 调试 WebView
- [ ] Console 无红色错误；Network 面板全部请求为 appassets.androidplatform.net（或 .sandbox），无外网请求

## 7. e-ink 专项（掌阅实机）

- [ ] 翻页无残影异常（分页模式应单帧位移）
- [ ] 面板弹出/收起无鬼影（若有机身"应用刷新"设置，对比开/关）
- [ ] 6–8 英寸屏：tap zone 大小合适、面板全屏展示
- [ ] 10.3 英寸（若有）：面板以侧栏呈现
- [ ] 息屏/锁屏后回来状态完好

## 8. 已知边界（M1 预期行为，不算失败）

- MathJax 书籍公式不渲染（mathjax 资产尚未打包，仅路由已就绪）
- 朗读/词典/搜索宿主侧尚未接线（面板存在但宿主服务 M2+）
- 高亮/书签的 EPUB 写回在 M3
